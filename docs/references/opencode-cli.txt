# opencode CLI 参考

## 基本用法

```bash
# 单次对话
opencode run <prompt>

# 带会话续接
opencode run --session <session_id> <prompt>

# 指定模型
opencode run --model <provider/model> <prompt>

# 指定 agent
opencode run --agent <agent_name> <prompt>
```

## codeClaw 集成方式

```bash
opencode run --session <session_id> [--model <model>] [--agent <agent>] <prompt>
```

- `--session`：会话 ID，codeClaw 按 `user_id:chat_id` 维度映射
- 输出读取：逐行 stdout，idle 超时由 `OPENCODE_IDLE_TIMEOUT_SECONDS` 控制
- 会话管理：opencode 自行管理上下文窗口和压缩，codeClaw 不介入

## 配置项

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `OPENCODE_CLI_BIN` | `opencode` | 二进制路径 |
| `OPENCODE_MODEL` | （空） | 形如 `provider/model` |
| `OPENCODE_AGENT` | （空） | `--agent` 参数 |
| `OPENCODE_IDLE_TIMEOUT_SECONDS` | `120` | 单行 stdout idle 超时 |
| `OPENCODE_SESSION_STORE_PATH` | `./runtime/server/opencode-sessions.json` | session ID 持久化 |

## 自定义模型注册

百炼上有、但 opencode 内置注册表（`~/.cache/opencode/models.json`）未收录的模型，需先在
`~/.config/opencode/opencode.jsonc` 注册才能被 `--model` 引用：

```jsonc
{
  "provider": {
    "alibaba-cn": {
      "models": {
        "deepseek-v4-flash-0731": {
          "name": "DeepSeek V4 Flash 0731",
          "reasoning": true,
          "options": { "reasoningEffort": "high" }
        }
      }
    }
  }
}
```

codeClaw 通过 `OPENCODE_CONFIG_CONTENT` 注入的配置（permission / instructions / plugin）与这份
全局配置是**合并**关系，不会覆盖 provider 注册。

### 推理模型必须带 reasoning: true

opencode 只在模型声明了 reasoning 能力时，才给百炼请求下发 `enable_thinking`：

```js
if (model.providerID === "alibaba-cn" && model.capabilities.reasoning
    && model.api.npm === "@ai-sdk/openai-compatible"
    && !modelId.includes("kimi-k2-thinking")) body.enable_thinking = true;
```

漏掉这个标记的后果：百炼不返回 `reasoning_content`，模型的思考过程只能折进 `content`，
于是**思考过程混入正文**，飞书和微信一起中招。内置注册表收录的模型自带该标记，所以只有手写
注册的模型会踩到。

标记正确时思考走独立的 `reasoning` 事件，而 `OpenCodeCliClient._extract_text_delta` 只放行
`type == "text"`，思考进不了回复；`run --format json` 非交互模式默认不发 reasoning 事件，
排查时需加 `--thinking` 才能观察到。

### 推理强度 reasoning_effort

百炼文档原文：

> deepseek-v4-pro、deepseek-v4-flash 和 deepseek-v4-flash-0731 默认开启思考模式。
> 通过 `reasoning_effort` 参数可以调整推理强度，可选值为 `low`、`medium`、`high`、`xhigh` 和
> `max`，默认为 `high`。其中，`low` 和 `medium` 的效果等同于 `high`；`xhigh` 的效果等同于 `max`。

即实际只有两档：`{low, medium, high}` → high，`{xhigh, max}` → max。写 `low` 等于不写，
想加深推理只有 `xhigh`/`max` 有效，代价是延迟和 token 上升。opencode 侧键名用 camelCase 的
`reasoningEffort`，由 `@ai-sdk/openai-compatible` 转成 `reasoning_effort` 下发。
