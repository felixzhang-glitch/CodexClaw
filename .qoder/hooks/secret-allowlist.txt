# .qoder/hooks/secret-allowlist.txt
#
# pre-push 密钥扫描白名单。个人专属条目请写到同目录的
# secret-allowlist.local.txt（已 gitignored），本文件用于随仓库共享的条目。
#
# 支持三种条目格式（每行一条，# 开头为注释）：
#
#   path:<glob>          整个文件跳过扫描，例：path:docs/references/*.txt
#   regex:<pattern>      命中该正则的“值”一律放行，例：regex:^sk-example-
#   fingerprint:<sha1>   精确放行某一处命中；扫描报告会直接给出可粘贴的行
#
# 另一种更就近的方式：在代码行尾加注释 `secret-scan: ignore`
# 或 `pragma: allowlist secret`，该行将被跳过。
#
# 注意：放行前请先确认确实是示例值/占位符。真实密钥一旦进入 commit
# 就应视为已泄露，正确做法是轮换密钥并清理历史，而不是加白名单。
