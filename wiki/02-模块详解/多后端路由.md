# 多后端路由

## 模块职责

运行时多后端路由：持有 codex / claude / qodercli 三个后端客户端实例，对外暴露与单后端相同的接口（chat / chat_stream / cancel / close），作为 drop-in 替换注入两个 handler。支持运行时切换与状态持久化。

## 核心接口/类

### `AgentRouter`

- **用途**：多后端路由器，实现 `BackendClient` Protocol
- **关键方法**：
  - `chat(messages, trace_id)` → 转发到活跃后端
  - `chat_stream(messages, trace_id)` → 转发到活跃后端
  - `cancel(trace_id)` → 广播到所有后端（非活跃后端无匹配进程时自动返回 False）
  - `switch(name)` → 切换活跃后端并持久化
  - `active` → 当前后端名称
  - `available()` → 可选后端列表

### `BackendClient` Protocol

```python
class BackendClient(Protocol):
    async def chat(self, messages, trace_id) -> str: ...
    def chat_stream(self, messages, trace_id) -> AsyncIterator[str]: ...
    def cancel(self, trace_id) -> bool: ...
    async def close(self) -> None: ...
```

- **用途**：handler 层的类型标注，使任何后端客户端或 router 可注入

### `ClaudeCliClient`

- **用途**：Claude Code 族 CLI（claude / qodercli）封装
- **调用方式**：
  - 非流式：`<bin> -p --output-format json --add-dir <work_dir> [perms] <prompt>`
  - 流式：`<bin> -p --output-format stream-json [--include-partial-messages] [--verbose] --add-dir <work_dir> [perms] <prompt>`
- **权限差异**：
  - claude：`--permission-mode auto`（root 下最大权限）
  - qodercli：`--dangerously-skip-permissions`
- **qodercli 限制**：不支持 `--verbose`、`--include-partial-messages`

### 持久化

切换后写入 `runtime/server/backend.json`（原子写：先写 `.tmp` 再 `os.replace`）。启动时从该文件加载；文件不存在则使用 `ACTIVE_BACKEND` 环境变量默认值。

## 设计模式

| 模式 | 应用位置 | 意图 |
|------|----------|------|
| 外观模式 | `AgentRouter` | 统一接口封装多个后端 |
| 策略模式 | `switch(name)` | 运行时切换活跃后端策略 |
| Protocol | `BackendClient` | 鸭子类型协议，不强制继承 |

## 注意事项

- `cancel()` 广播到所有后端，但非活跃后端因无匹配进程会返回 False，不会污染 `_cancel_requests` 集合
- claude 和 qodercli 使用 `CODEX_WORK_DIR` 下的 `claude/`、`qodercli/` 子目录，避免共享本地工具状态
- 后端切换成功后会清空当前会话历史，避免旧后端的工具/skills/回答风格污染新后端
- `ClaudeCliClient` 同时服务 claude 和 qodercli，因为二者是同族 CLI（相同 output-format）
