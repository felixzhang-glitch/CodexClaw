# 应用入口与配置

## 模块职责

FastAPI 应用入口，负责路由注册、全局组件初始化（会话管理器、后端路由器、飞书客户端、提醒调度器）、Webhook 端点暴露与异常兜底。

## 关键文件

| 文件 | 职责 | 行数 |
|------|------|------|
| `lib/python/app/main.py` | FastAPI 实例创建、路由注册、组件初始化、启停事件 | 118 |
| `lib/python/app/config.py` | pydantic-settings 环境变量绑定与配置属性 | 113 |
| `lib/python/app/commands.py` | 命令解析（/help /new /reset /compact /backend /codex 等） | 130 |
| `lib/python/app/logging.py` | JSON 结构化日志配置 | 30 |

## 核心接口/类

### `Settings`

```python
class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file="conf/.env", case_sensitive=False, extra="ignore")
    feishu_app_id: str = Field(default="", validation_alias="FEISHU_APP_ID")
    # ... 40+ 配置字段
```

- **用途**：集中管理所有环境变量配置，通过 `@lru_cache` 单例化
- **调用方**：所有模块通过 `get_settings()` 获取

### `process_command`

```python
def process_command(raw_text, session_manager, session_key, router=None) -> CommandResult | None
```

- **用途**：解析并执行聊天命令（/help /new /reset /compact /backend /codex /claude /qodercli）
- **返回值**：`CommandResult(handled, reply_text)` 或 `None`（非命令）
- **调用方**：飞书 handler、微信 handler

### `build_help_text`

```python
def build_help_text(*, include_remind: bool = True) -> str
```

- **用途**：统一生成帮助文本，飞书含 `/remind`，微信标注不支持

## 依赖关系

### 上游依赖

- **core.agent.router**：创建 `AgentRouter` 实例注入 handler
- **core.session.***：创建 SessionManager / Deduplicator / TaskRegistry / ReminderScheduler

### 下游被依赖

- **channel.feishu.handler**：`FeishuWebhookHandler` 在 main.py 中实例化
- **channel.wechat.handler**：`WeChatWebhookHandler` 在 main.py 中实例化

### 外部依赖

- **fastapi**：Web 框架
- **pydantic-settings**：配置绑定
- **uvicorn**：ASGI 服务器（由 `bin/server` 脚本启动）

## 注意事项

- `get_settings()` 使用 `@lru_cache(maxsize=1)`，配置在进程生命周期内不可变
- `/skills` 命令不在 `process_command` 中处理，而是由 handler 层异步调用 `ClaudeCliClient._build_skill_summary`
- `send_reminder` 回调在 main.py 中定义，通过飞书 client 主动发送消息到 chat_id
